    2) Analyse critique de la modélisation
    
        
    Point fort : l'utilisation d'optional intervals par couple (tâche, station) est la bonne technique CP-SAT pour imposer des contraintes de ressources dépendantes d'une affectation.
    
        
    Point subtil : pour une précédence entre stations différentes, le modèle impose seulement station[pred] ≤ station[succ], pas end[pred] ≤ start[succ]. On modélise donc un flux de ligne (régime cyclique), pas un mono-produit strict.
    
        
    Conséquence observée : certaines tâches de Station_B peuvent commencer à t=0 même si leurs prédécesseurs sont sur Station_A, ce qui reste faisable dans cette logique de pipeline.
    
        
    Si besoin métier différent : ajouter une contrainte temporelle globale sur toutes les précédences transformerait le modèle vers un flux mono-produit.
